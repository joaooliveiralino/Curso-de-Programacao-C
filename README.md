# 📘 Curso de Programação em C

Repositório com meus estudos, aulas e exercícios do **Curso de Programação Completo em C**, do canal [Programe Seu Futuro](https://www.youtube.com/@ProgrameSeuFuturo) no YouTube.

## 🎯 Sobre

Este repositório reúne o código que venho desenvolvendo ao longo do curso, aula por aula, como forma de praticar lógica de programação e a linguagem C desde o básico.

## 🛠️ Ambiente

- **Sistema operacional:** Linux Mint
- **Linguagem:** C
- **Compilador:** GCC
- **IDE:** Code::Blocks

## 📂 Estrutura

Cada pasta corresponde a uma aula do curso, contendo o código-fonte (`.c`) e o projeto do Code::Blocks correspondente:

```
Curso-de-Programacao-C/
├── Aula04/
│   └── main.c
├── Aula05/
│   └── main.c
├── Aula08/
│   └── main.c
...
```

## ▶️ Como compilar e executar

Cada exercício pode ser compilado individualmente pelo terminal:

```bash
gcc main.c -o programa
./programa
```

Ou, se preferir, basta abrir o arquivo `.cbp` correspondente no Code::Blocks.
